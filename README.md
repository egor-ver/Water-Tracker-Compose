# 💧 Water Tracker

Android-приложение для отслеживания дневной нормы воды. Пет-проект, написан в процессе изучения современной Android-разработки.

## Возможности

- Быстрое добавление воды в один тап: 250 / 500 / 1000 мл
- Настройка персональной дневной цели
- Визуальный индикатор прогресса до цели
- Автоматический сброс счётчика при смене дня
- История потребления по дням
- Удаление последней записи

## Стек

| Категория | Технологии |
|-----------|------------|
| Язык | Kotlin |
| UI | Jetpack Compose, Material 3 |
| Архитектура | MVVM |
| Хранение данных | Room (история по дням), DataStore (текущее значение и цель) |
| Асинхронность | Coroutines, Flow |
| Сборка | Gradle (KSP) |

## Как устроено

Данные текут реактивно снизу вверх: репозиторий отдаёт `Flow`, ViewModel на него подписан, Compose перерисовывает UI при изменении состояния.

- **Data-слой** — `Room` хранит историю (`WaterDay`), `DataStore` хранит текущее значение и цель; `WaterRepository` объединяет оба источника.
- **UI-слой** — `WaterViewModel` держит состояние экрана и обрабатывает действия, `WaterScreen` / `HistoryScreen` рисуют интерфейс на Compose.
