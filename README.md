# Water Tracker

Приложение для отслеживания выпитой воды за день.

## Стек
- Kotlin
- Jetpack Compose
- MVVM (ViewModel)

## Возможности
- Добавление воды (250 / 500 / 1000 мл)
- Установка дневной цели
- Прогресс-бар выполнения
- Удаление последней порции

## В планах
- Сохранение данных (DataStore)
- Сброс счётчика по дате
- История по дням (Room)
